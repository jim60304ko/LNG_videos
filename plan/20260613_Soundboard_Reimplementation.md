# Future Plan: Soundboard Re-implementation 🔊

**建立時間**: 2026年6月13日

## 📌 背景
為了優化首頁內容與專注於影片存檔核心功能，暫時移除現有的語音迷因板 (Soundboard) 功能。此功能將規劃於未來版本中以更完整、更具互動性的方式重新回歸。

## 🎯 未來目標
- [ ] **音檔資源優化**: 重新整理成員經典語音，並優化音檔加載效能。
- [ ] **互動設計升級**: 
  - 實作類似 Launchpad 的打擊墊介面。
  - 增加語音分類（如：六嘆專區、鳥屎專區等）。
  - 支援熱鍵觸發。
- [ ] **彩蛋系統**: 
  - 重新設計隱藏於 UI 中的互動彩蛋。
  - 增加隨機播放經典語音的功能。

## 🛠️ 待解決問題
- [ ] 音檔版權與來源標記。
- [ ] 行動裝置上的音效播放限制處理（User Interaction Required）。
- [ ] 本地快取音檔以減少流量消耗。

## 📅 預計時程
待定（納入 Phase 4 或 5 的開發目標）。
