# LNG Portal Project - 第三階段開發計畫：進階互動與數據功能

**建立日期**: 2026年5月25日
**階段**: 第三階段 - 功能擴充與深度互動 (Phase 3)

## 1. 專案目標
在現有的多頁面導航與影片展示基礎上，加入更深度的互動功能（收藏、迷因）與數據洞察（歷史回顧、統計圖表），將網站從單純的「影片目錄」升級為「LNG 粉絲的專屬社群儀表板」。

## 2. 核心功能規劃

### Feature 1: 「我的收藏」系統 (Local Favorites)
- **概念**: 允許使用者將喜歡的影片加入專屬清單，方便隨時回味。
- **技術實作**: 
  - 使用瀏覽器 `localStorage` 儲存收藏影片的 ID，無需後端資料庫。
  - 建立一個全新的 `/favorites` 頁面（或整合在 Video 視圖中）來展示收藏清單。
- **UI 設計**: 
  - 在每張影片卡片的角落新增一個愛心/書籤圖示 (❤️/🔖)。
  - 點擊時要有微小的彈跳與顏色變化動畫。

### Feature 2: 「歷史上的今天」 (On This Day)
- **概念**: 每日動態推薦過去同月同日（或當週）發布的經典影片。
- **技術實作**: 
  - 在 `Home.tsx` 中加入一段邏輯，比對今日日期與 `videos.json` 中影片的 `publishedAt`。
  - 隨機挑選 1~2 部符合條件的影片進行展示。
- **UI 設計**: 
  - 放置在首頁卡片網格上方或下方，設計為一個橫向的特別展示區塊，帶有「時光機」的視覺暗示（例如漸變色邊框）。

### Feature 3: 數據可視化儀表板 (Analytics Dashboard)
- **概念**: 以圖表形式展示 LNG 頻道的歷史數據。
- **技術實作**: 
  - 引入輕量級圖表套件（如 `recharts` 或 `chart.js`）。
  - 建立全新的 `/analytics` 頁面。
  - 根據 `videos.json` 動態計算：歷年發片量趨勢、點閱率 Top 10、精華與存檔比例。
- **UI 設計**: 
  - 充滿科技感與科技感的深色圖表設計，搭配 LNG 亮黃色作為數據高光。

### Feature 4: 語音迷因板 (Soundboard / Easter Eggs)
- **概念**: 在網站中藏入能發出經典音效的互動彩蛋。
- **技術實作**: 
  - 準備數個極短的音效檔 (`.mp3` 或 `.wav`) 存放在 `src/assets/audio/`。
  - 使用 React 的 `Audio` API 在點擊特定元素時觸發播放。
- **UI 設計**: 
  - 可以將音效按鈕做成類似打擊墊 (Launchpad) 的九宮格，放置在專屬的 `/soundboard` 頁面，或是巧妙地隱藏在首頁的 Logo 中。

## 3. 開發路線圖 (Roadmap)

- **Step 1**: 實作 Feature 1（我的收藏）與 Feature 2（歷史上的今天），這兩項能最快提升日常互動率。
- **Step 2**: 實作 Feature 3（數據儀表板），這需要引入新套件並處理資料計算。
- **Step 3**: 實作 Feature 4（語音迷因板），並進行全站音效測試與行動端相容性檢查。
